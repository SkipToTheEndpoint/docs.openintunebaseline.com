---
title: Contributing
description: How to contribute to the OpenIntuneBaseline and to these docs.
---

The OIB is a community-driven project. Please raise an [issue](https://github.com/SkipToTheEndpoint/OpenIntuneBaseline/issues), post in [discussions](https://github.com/SkipToTheEndpoint/OpenIntuneBaseline/discussions), or open a pull request.

To fix or improve a page on this site, use the **Edit page** link at the bottom of any page.
